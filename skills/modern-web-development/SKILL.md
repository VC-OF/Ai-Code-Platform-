# Modern Web Development & UI Guidance

## Design & Aesthetics Principles

1. **Rich Aesthetics by Default**:
   - Deliver sleek, high-contrast, polished UI interfaces.
   - Use intentional HSL color palettes and CSS variables for theming.
   - Employ glassmorphism (`backdrop-filter: blur(...)`), subtle border highlights, and ambient glow effects.

2. **Typography & Layout**:
   - Modern font stacks (Inter, JetBrains Mono, Outfit).
   - Fluid typography with consistent spacing scales (4px, 8px, 12px, 16px, 24px, 32px).
   - Clean flexbox and grid layouts responsive across viewport sizes.

3. **Motion & Interaction**:
   - Subtle transitions on hover, focus, and state changes (150ms-250ms cubic-bezier).
   - Micro-animations for feedback, badge indicators, and progress status.
